# Strategic questions

Asked **before** grouping into areas: the answers tell which areas matter to the business (core vs the rest).

## The default set (replaceable — a project can provide its own)
1. **Money:** where does the organization earn and where does it lose / want to save?
2. **Risks and opportunities:** what can go wrong (penalties, losing a customer, outages) and what would be an advantage?
3. **Integrations:** with which systems and partners must we cooperate; what is outside our control?
4. **Regulations:** which laws, contracts, audits constrain the solution?
5. **Success metric:** which number does the business want to improve and **what wins in a conflict** between two goals?

## How to assess coverage
1. For each question first write **a gap checklist** — 3–6 things you need to know for the answer to be complete.
2. Match quotes from the bank **by meaning** (not by keywords).
3. The status follows from **the coverage of the checklist**, not from the number of quotes:
   `answered` (every item has a quote) · `partial` · `missing` · `deferred` (the human decided) · `not applicable`.
4. Phrase the gap description so that the human can answer in one paragraph.
