# Internationalization (i18n) in the interface

Moved from the frontend-developer import (`staff.md`, "i18n"), supplemented with the `Intl` API and 2026 practice.

## i18n vs l10n

- **i18n** — preparing the architecture: texts outside the code, locale-dependent formats, a layout ready for RTL and longer
  labels. One-off, architectural work.
- **l10n** — translating and adapting content for a market. A continuous process. Good i18n = a new language without a code change,
  only a new set of translations.

## Rules

- **Messages in the ICU MessageFormat format** (FormatJS/`react-intl`, `i18next` with ICU, Angular `$localize`/i18n with
  ICU, Transloco) — with parameters and plurals in the message, not assembled by concatenation ("You have " + n + " files").
- **Plurals** depend on the language: Polish has the categories `one` (1), `few` (2–4, 22–24…, excluding 12–14), `many` (0, 5–21,
  25…), `other` (fractions). `Intl.PluralRules('pl').select(n)` returns the category — do not assume "1 vs the rest".
- **Formatting** always through `Intl`: `DateTimeFormat`, `NumberFormat` (currencies, units, `compact`),
  `RelativeTimeFormat` ("3 days ago"), `ListFormat` ("a, b and c"), `Collator` (sorting with Polish characters),
  `DisplayNames`, `Segmenter` (splitting text into characters/words — emoji, languages without spaces). Time zones:
  `timeZone` in the formatter; in new code `Temporal` where available (lang-javascript).
- **Locale** from the user's settings / `navigator.languages` / the `Accept-Language` header, stored in the URL
  (`/pl/…`) or the profile; set `<html lang>` and `dir`.
- **RTL** — not only the text, the whole layout: CSS logical properties (`margin-inline-start`, `inset-inline-end`,
  `padding-block`) instead of `left/right`, flipping directional icons, `dir="auto"` for user content (fe-css).
- **Text length** — German/Finnish are sometimes 30–40% longer; do not design for a fixed width, test
  with pseudolocalization.
- **SSR** — a locale/time-zone-dependent format computed on the server must match the client (hydration mismatch —
  fe-architecture `.claude/skills/fe-architecture/references/rendering-models.md`).
- Do not translate by gluing sentence fragments together and do not put text into images; context and a description for the translator with
  every key.
