# Skróty A–Z (krótkie hasła)

Źródła: `dom-ev-charging/references/*.md` (import 2024–2025) i wiedza ogólna; **[do weryfikacji]** = sprawdź.

| Skrót | Rozwinięcie | Uwaga łatwa do pomylenia |
|---|---|---|
| AC / DC | prąd przemienny / stały | limit AC to często ładowarka pokładowa auta, nie stacja |
| AFIR | unijne rozporządzenie o infrastrukturze paliw alternatywnych | zakres i terminy **[do weryfikacji]** |
| CCS2 | Combined Charging System, wariant Type 2 + DC | w Europie „CCS” = CCS2 |
| CDR | Charge Detail Record | niezmienny; korekta = CDR kredytowy |
| CPMS / CSMS | system zarządzania punktami / stacjami | ta sama rola; nazwa kanoniczna CSMS |
| CPO | Charge Point Operator | rola rynku → `dom-ev-market-roles` |
| DLM | Dynamic Load Management | ogranicza sumę mocy do przyłącza; nie jest taryfą |
| eMSP | e-Mobility Service Provider | rola, nie typ firmy |
| EMAID / EVCO | identyfikator kontraktu | format → `dom-ev-identifiers`; EVCO jako synonim **[do weryfikacji]** |
| EVCC / SECC | kontroler komunikacji pojazdu / ładowarki (ISO 15118) | **[do weryfikacji]** |
| EVSE | Electric Vehicle Supply Equipment | jednostka „jedno auto naraz” |
| kW / kWh | moc / energia | pojemność baterii w kWh, moc ładowarki w kW |
| Mode 1–4 | tryby ładowania wg IEC 61851 | tylko pojęcie; sprzęt poza zakresem **[do weryfikacji]** |
| NEVI | federalny program stacji w USA (23 CFR 680) | jego wzór uptime wyłącza m.in. planowany serwis → `dom-ev-kpi-analytics` |
| OCPI / OCPP | roaming CPO↔eMSP / ładowarka↔CSMS | różne warstwy |
| OCPP 1.6 / 1.6J / 2.0.1 / 2.1 | wersje protokołu ładowarka↔CSMS | 1.6J = 1.6 przez JSON/WebSocket; 2.x niezgodne z 1.6, inne statusy złącza (`Occupied`) |
| SoC / SoH | stan naładowania / stan zdrowia baterii | SoC zmienia się w sesji, SoH powoli w latach |
